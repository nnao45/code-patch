インスペクタが選択した要素に対してHTMLファイルを直接編集してください。

## 手順

### 1. コンテキスト読み込み
`.inspector-context.json` を Read ツールで読む。
ファイルが存在しない場合は「先に `bun run serve` でサーバを起動し、ブラウザで要素を選択してください」と伝えて終了。

### 2. 対象HTMLファイルの特定
`filename` フィールドのファイル名を使い、以下のコマンドで探す:
```
find . -name "<filename>" -not -path "*/node_modules/*" -not -path "*/.git/*"
```
- 1件: そのファイルを使う
- 複数件: ユーザに選択を求める
- 0件: ユーザにパスを教えてもらう

### 3. HTMLファイルを読む
対象ファイルを Read ツールで読む。

### 4. 編集を適用
コンテキストの情報を手がかりに正確な変更箇所を特定し、Edit ツールで直接編集する。

参照すべきコンテキストフィールド:
- `selector` — 選択された要素の CSS セレクタ
- `outerHTML` — 要素の HTML（変更前の正確な内容）
- `cssRules` — その要素にマッチしている CSS ルール一覧
- `jsLines` — 要素の id/class を参照しているインライン JS の行

変更対象:
- HTML: `outerHTML` と一致する箇所
- CSS: `cssRules` に含まれるルールが書かれている `<style>` ブロック内
- JS: `jsLines` に含まれる行が書かれている `<script>` ブロック内

## ユーザの指示

$ARGUMENTS

指示が空の場合は、コンテキストの内容（selector・css・js）を要約してユーザに「何を変更しますか？」と聞く。
